# projet\_conception
# Balade dans un labyrinthe

L'architecture du projet suit la structure standard Maven.
création du fichier .gitignore et pom.xml

## Lancer l'application

Installez un JDK et Apache Maven, puis exécutez la commande suivante depuis la
racine du projet :

```sh
mvn exec:java
```

Cette commande démarre l'application graphique du labyrinthe. Pour compiler et
lancer les tests, exécutez `mvn test`.
